# 2026-10-26：恢复已验证循迹基线

## 现象

`final-work` 在加入自适应速度和弯道 PID 后，实车循迹明显差于参考工程
旧版基线工程。尤其在外侧数字探头已经检测到黑线时，
车辆仍可能保持两轮近似等速并继续向赛道外侧行驶。

## 证据与根因

1. 参考工程在单侧外沿探头触发时立即输出固定差速：外轮 `4500`、内轮 `1400`。
2. 新控制器把外沿信号降级为 PID 方向提示，转向幅度仍取决于中间两路 ADC 差值。
3. 当两个中间探头同时离线且读数接近时，PID 输出接近零，外沿提示不能产生有效转向。
4. 新控制器还把普通速度提高到 `4300`、居中速度提高到 `5000`，进一步缩短了纠偏时间。
5. 原测试把“外沿单独触发时两轮等速”作为正确结果，因而没有捕获上述回归。

## 修改位置

- `Core/Src/control/line_follow_control.c`
  - 普通循迹恢复参考工程的双路 ADC PID 和一阶微分滤波。
  - 单侧外沿探头触发后立即进入固定差速救线。
  - 普通救线释放时同步当前误差并保留基础速度。
  - 保留最终工程掉头后使用的低速强制找线接口。
  - ADC 绝对阈值只用于掉头后的强制回线确认，不再干预普通循迹。
  - 外侧探头短暂丢失时最多保持有限采样周期，避免无限固定差速造成左右摆动。
- `Core/Inc/config/car_parameters.h`
  - 基础速度恢复为 `3700`。
  - 固定救线参数恢复为 `4500/1400`。
  - 暂时移除第二阶段才需要的自适应速度和弯道增强参数。
- `tests/native/test_line_follow_control.c`
  - 用第一阶段基线契约替换自适应提速测试。
- `tests/native/test_car_control_compat.c`
  - 验证旧四路混合循迹入口同样产生固定差速救线。
