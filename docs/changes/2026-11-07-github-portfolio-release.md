## 需要提炼的工程经验

README 至少总结以下探索结果：

- 数字探头极性错误会让救线方向整体反转，必须先观察原始输入再调 PID。
- 中间模拟量探头适合连续位置 PID，外侧数字探头适合提供大偏差方向信息，两者不应互相覆盖。
- 外侧探头触发后需要方向锁存，回到中间区域后需连续多帧确认再交还 PID。
- PID 在任务切换、掉头和重新循迹时必须重置历史项，避免积分和微分残留造成瞬时反打。
- 提高控制频率不一定提高控制质量；传感器、OLED、串口和 DMP FIFO 的时间预算必须统一考虑。
- MPU6050 姿态少读首先应排查 FIFO 消费延迟，不能用比例系数掩盖数据链问题。
- 红牌停车需要锁存，绿牌放行需要更严格的连续确认，避免移开红牌后自动恢复。
- 编译通过、主机测试、烧录成功和完整实车验证是四种不同证据，文档必须分别标注。
