# 2026-10-25：居中加速与偏离降速循迹

## 现象

能跑通的普通驾照版本整体速度偏慢，但弯道一旦触发外侧传感器就立即使用较大的固定差速，表现为直道不快、弯道突然猛纠偏。控制器没有利用“中间传感器稳定保持黑线的时间”提高速度，也没有在单侧持续丢线时提前降速。

## 根因

1. PID 基础速度固定以 `3700` 为目标，居中稳定时没有快速档。
2. 外侧传感器单个样本即可进入 `4500/1400` 救线，容易受瞬时抖动影响。
3. 中间单侧或双侧丢线没有独立持续时间计数。
4. PID 输出仅由最终轮速限幅间接限制，偏差较大时可能形成过强差速。

## 修改

- 中间两路稳定居中连续 10 个新样本，约 200 ms 后，基础速度逐步提高到 `4300`。
- 非居中状态连续 3 个新样本，约 60 ms 后，目标速度降低到 `2800`。
- 加速每个新样本增加 `60`，降速每个新样本最多降低 `250`，使减速快于加速。
- 普通 PID 输出限制为正负 `2000`；谨慎状态进一步限制为正负 `1200`。
- 外侧传感器连续 2 个新样本触发，约 40 ms 后才进入救线。
- 救线锁存后，反侧外沿同样需要连续 2 个新样本才允许改变救线方向，单帧抖动不会让车突然反向纠偏。
- 普通外侧救线改为 `3600/1400`，降低固定差速强度。
- 两个中间 ADC 和两个外侧传感器均未检测到黑线连续 5 个新样本，约 100 ms 后，按最近偏差方向以 `2400/700` 低速搜索。
- 完全丢线后的低幅 ADC 噪声不会覆盖最后一次有效偏差方向。
- 保留约 3 秒的恢复超时，无法回中时安全停车并显示 `LINE / BAD VALUE`。

## 未验证

- `4300` 快速速度需要在真实直道和缓弯验证，不能由编译结果证明安全。
- 黑线 ADC 阈值 `2000`、居中误差 `500` 仍需结合 OLED 或串口原始数据校准。
- 如果外侧救线变得不足，应先逐步调整 `3600/1400`，不要同时修改 PID 和传感器阈值。
- 单次外侧候选或刚开始完全丢线时会立即朝较低速度靠近，这是有意的安全降速；进入锁存救线和低速搜索仍分别要求 2 个与 5 个新样本。
