# 2026-10-28：循迹原始数据串口遥测

## 目的

针对逆时针入弯时内侧传感器可能持续主导控制的问题，增加一条只读诊断链路，
把循迹输入和控制输出传到 SuperCom。此修改不改变 PID、采样周期或电机参数。

## 串口设置

- 接口：USART3，PB10 为 TX，PB11 为 RX。
- 波特率：115200。
- 数据格式：8 数据位、无校验、1 停止位、无流控。
- 输出条件：小车处于 normal 模式、正在运行且电机请求为行驶状态。
- 输出周期：50 ms。

## 数据格式

首次输出表头：

```text
LF,time,left_adc,right_adc,outer_r,outer_l,pid,left_pwm,right_pwm,mode
```

随后每行是一帧 CSV 数据，例如：

```text
LF,12540,3650,820,0,1,-2830,870,6500,P
```

字段含义：

- `time`：系统毫秒计时。
- `left_adc`、`right_adc`：左右内侧模拟传感器 ADC 原始值。
- `outer_r`、`outer_l`：左右外侧数字传感器黑线状态。
- `pid`：本次最终循迹控制量，包含中间 PID 与外侧辅助差速。
- `left_pwm`、`right_pwm`：循迹模块给出的左右轮目标值。
- `mode`：`P` 为 PID，`L`、`R` 为外侧救线，`F` 为故障。
