# 2026-10-26：增加外侧循迹探头 OLED 诊断

## 目的

定位左、右外侧数字循迹探头在实车弯道中的软件映射问题，不改变循迹控制逻辑和 PID 参数。

## 修改

- `DisplayModel` 增加 `outer_right` 与 `outer_left` 快照字段。
- OLED 速度行末尾增加 `R1L0` 诊断字段：前一个数字为程序识别的右外侧探头状态，后一个数字为左外侧探头状态。
- OLED 第三行临时显示 `T:左目标/右目标 模式`，例如 `T:1400/4500 L`，用于确认控制器实际给出的左右轮目标速度。
- `AppRuntime` 将当前传感器快照传给显示服务。
- `AppRuntime` 将最近一次循迹输出的左右目标和模式传给显示服务；模式 `L/R/P/F` 分别表示左救援、右救援、PID、故障。

## 验证

- 先修改显示测试，确认新增字段缺失时编译失败。
- 实现后 Windows GCC 原生测试：18/18 通过。
- Keil ARM Compiler 5.06 update 7 全量构建：0 Error(s), 0 Warning(s)。

## 2026-10-26 后续：救线释放防抖

- 现象确认：左转过程中 OLED 模式从 `L` 突然变成 `P`，车辆随即放弃弯道。
- 修改：普通外侧救线不再因一次外侧探头变白立即释放；要求中间探头连续达到居中确认次数后才回到 PID。
- 验证：原生测试 18/18 通过，Keil 全量构建 0 Error(s), 0 Warning(s)。
