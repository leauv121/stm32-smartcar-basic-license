# 2026-10-28：normal 模式外侧传感器渐进 PID 辅助

## 现象与证据

SuperCom 日志显示，问题方向在进入弯道后，左外侧数字传感器长期触发。
旧控制会停止中间两路 ADC 的 PID，直接输出固定的 `1400 / 4500` 轮速；
外侧信号短暂释放时又突然回到 PID，造成救线与直行状态反复切换。

## 修改

- normal 模式始终计算中间两路 ADC 的 PID。
- 外侧右/左触发只叠加正/负方向的辅助差速，不再覆盖 PID 输出。
- 外侧信号连续确认后才启动辅助；辅助按控制周期渐进增加。
- 外侧释放时，辅助按步长渐退；连续释放确认后显示为 PID 模式。
- 掉头后的强制低速找线仍保留原有固定差速，避免改变返程回线策略。

## 手动调参

参数位于 `Core/Inc/config/car_parameters.h`：

- `CAR_LINE_OUTER_ASSIST_MAX`：外侧辅助的最大差速。救线不够时每次增加 100；转向过猛时每次减少 100。
- `CAR_LINE_OUTER_ASSIST_STEP`：每个控制周期的辅助变化量。入弯辅助来得慢时每次增加 20；外侧附近抖动时每次减少 20。
- `CAR_LINE_OUTER_ASSIST_ON_CONFIRM_SAMPLES`：外侧触发确认次数。误触发时增加，需立即救线时减少。
- `CAR_LINE_OUTER_ASSIST_OFF_CONFIRM_SAMPLES`：外侧释放确认次数。释放后反复切换时增加。

初始值为最大辅助 800、步长 100、触发确认 2 次、释放确认 3 次。
PID 参数仍沿用用户当前设置：`KP=1.3`、`KI=0`、`KD=0.4`。
