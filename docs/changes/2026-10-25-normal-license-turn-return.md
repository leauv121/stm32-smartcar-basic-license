# 2026-10-25：普通驾照 180 度掉头与返程终点检测

## 现象

普通驾照模式遇到障碍物后只转约 90 度；掉头后还可能因为两个外侧循迹探头同时压线而提前结束任务。指导书要求车辆从障碍物处掉头，沿轨迹返回出发点停止。

## 根因

1. `AppRuntime` 启动转弯控制时把目标角度写成了 `90.0f`，对应普通右转而不是掉头。
2. 返程终点曾使用 `outer_left && outer_right` 判断，没有证明车辆已经离开障碍物区域，也不能唯一表示出发点。
3. 红灯等待与障碍物停车都是停车状态，实车观察时容易混淆；前者应只由绿灯解除，后者停车 1 秒后进入掉头。

## 修改

- 掉头目标角度改为 180 度。
- 转角按请求方向的净 Yaw 增量累计；反向回摆会扣除，避免不足 180 度就提前完成。
- 障碍物检测距离保持不超过 20 cm。
- 新增大于 30 cm 的离开阈值，形成距离滞回。
- 掉头结束后进入 `NORMAL_RETURN_CLEAR`，连续 3 个有效超声波样本确认离开原障碍物。
- 离开确认后进入 `NORMAL_RETURN`，再次连续 3 个样本检测到障碍物才结束任务。
- 删除“双外侧循迹探头同时压线就是出发点”的判断。
- 增加测试，确认红灯等待不会被时间或障碍物事件解除，只能由绿灯解除。
