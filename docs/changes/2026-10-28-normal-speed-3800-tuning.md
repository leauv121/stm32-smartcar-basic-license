# 2026-10-28：普通循迹 3800 试验与回退

## 背景

上一版本以 `3700` 作为普通 PID 循迹的稳态基准速度，已经通过实车验证。为进一步缩短运行时间，曾只把稳态基准速度提高到 `3800`，其余控制参数保持不变。实车随后出现左右无序摆动，因此按单变量 A/B 原则恢复到 `3700`。

## 修改范围

- `CAR_LINE_PID_BASE_SPEED`：试验时由 `3700` 改为 `3800`，实车异常后恢复为 `3700`。
- 启动速度仍为 `1800`，每个有效控制样本仍增加 `60`。
- 单轮上限仍为 `6500`。
- 外侧救线仍为 `4500/1400`，掉头仍为 `5000/-5000`，掉头后回线仍为 `2400/700`。
- 循迹控制测试最终继续验证稳态速度和普通救线返回 PID 后的速度均为 `3700`。

## 验证

- 提速 RED：修改测试后，5 个断言均报告期望 `3800`、实际 `3700`，测试退出码为 `5`。
- 回退 RED：恢复测试期望后，5 个断言均报告期望 `3700`、实际 `3800`，测试退出码为 `5`。
- 回退 GREEN：恢复生产参数后，循迹控制定向测试通过。
- 源码边界检查通过。
- UTF-8 检查通过。
- Keil ARM Compiler 5.06 update 7 全量 Rebuild：`0 Error(s), 0 Warning(s)`，并重新生成 HEX。

## 实车结论

- `3800` 已实车确认出现左右无序摆动，不作为当前可用参数。
- 当前代码恢复到此前已验证的 `3700` 基准速度。
- 恢复后的组合版本仍需与红牌 2 帧、绿牌 5 帧策略一起重新烧录确认；只有用户明确同意后才允许提交。
