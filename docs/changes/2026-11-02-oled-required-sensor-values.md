# OLED 补齐实验要求的传感器值

## 现象

OLED 正常页面显示了状态、轮速、电机目标值、航向角和电池字段，但没有显示颜色传感结果与超声波距离。电池采集尚未接入时还会显示误导性的 `0.0V`。

## 证据与根因

- `AppRuntime` 已经把轮速、超声波距离、颜色枚举和电池电压写入 `DisplayModel`。
- `DisplayService_FormatNormal()` 只使用了轮速、状态、模式、航向角和电池字段，遗漏了 `distance_cm` 与 `color`。
- 当前板级 ADC 只配置两路循迹输入，`battery_v` 没有实际采样来源。

根因是显示格式与实验验收项目没有保持一致，而原显示测试也没有断言距离和颜色。

## 修改位置

- `Core/Src/services/display_service.c`
  - 四行依次显示左右轮速、超声波距离与颜色、电池电压、运行状态与模式。
  - 颜色使用 `RED`、`GRN`、`OTH`、`UNK` 表示。
  - 距离或电池值未采集时显示 `N/A`，避免把零值伪装成测量结果。
- `tests/native/test_display_service.c`
  - 增加四项验收值的显示断言。
  - 增加未采集时 `N/A` 和 `UNK` 的断言。

## 验证结果

- 聚焦显示测试先在旧实现上按预期失败，修改后通过。
- 全部原生测试已执行：OLED 显示测试通过；`test_line_follow_control.c` 因工作区内既有循迹控制改动出现两条失败断言，本次未修改该模块。
- Keil Rebuild 通过：`0 Error(s), 0 Warning(s)`，已生成 HEX 文件。

## 未验证事项

- 尚未烧录到开发板验证 OLED 实际显示效果。
- 电池电压 ADC 通道、分压电阻比例和换算逻辑尚未接入，因此当前会诚实显示 `B:N/A`。
