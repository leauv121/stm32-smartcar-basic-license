# 四路 DO 输入与基础调参

## 信号与接线

四个 TCRT5000 从车头右侧到左侧依次连接：

```text
LINE1 -> PA6 -> 最右侧
LINE2 -> PA7 -> 右内侧
LINE3 -> PB0 -> 左内侧
LINE4 -> PB1 -> 最左侧
```

DO 是模块比较器输出的数字信号，因此 STM32 使用 GPIO 输入读取，不需要 ADC。

## 指导书控制顺序

- LINE1 检测黑线：强右转。
- LINE2 检测黑线：弱右转。
- LINE4 检测黑线：强左转。
- LINE3 检测黑线：弱左转。
- 其他组合：直行。

外侧传感器排在同侧内侧传感器之前，偏离较大时优先进行强纠偏。同一轮 `if/else if` 判断只执行一个动作。

实车测试发现，中间的 LINE2 与 LINE3 同时压住黑线时，原始顺序可能在弱右和弱左之间切换。当前工程在原判断之前增加了一个居中组合：当 LINE1、LINE4 位于白面，LINE2、LINE3 同时检测黑线时，直接保持直行。这样可以避免两侧车轮反复停转造成平均速度下降。

进一步测试发现，原弱转弯会直接停止内侧轮；当左右输入交替时，两侧轮子会反复停转，形成明显顿挫。当前参数改为：直行与转弯外侧轮 4500，弱转弯内侧轮 2800，强转弯内侧轮仍为 0。弱纠偏时两轮持续前进，因此平均速度更高、动作也更平滑。

## 50 ms 调度

SysTick 每 50 ms 将 `measure_flag` 置为 1，主循环看到标志后读取四路 GPIO 并执行循迹。中断只负责发出任务请求，不在中断中执行电机控制。

## 主要挑战

1. 四个模块的比较器阈值不同，需要逐个调节蓝色电位器。
2. 实物 DO 极性可能因模块版本不同而变化，必须确认黑线对应的实际输入电平。
3. 传感器高度、间距和左右对称性决定强弱转向的触发时机。
4. 左右电机在相同 PWM 下可能转速不同，直行时可能天然偏向一侧。
5. 转向力度过大时会在黑线两侧反复修正，表现为左右抖动。

## 推荐调参顺序

1. 架空车轮，逐个确认 LINE1～LINE4 的接线和转向方向。
2. 调节四个电位器，使黑线和白面的 DO 切换稳定。
3. 保持 50 ms 周期，先降低直行速度，让小车安全跑过弯道。
4. 调强转向速度，保证外侧传感器触发后能够拉回黑线。
5. 调弱转向速度，减少直线行驶时的左右摆动。
6. 最后才调整采样周期；周期太长会迟钝，太短会放大输入抖动。

本阶段暂不调整 `Kp`、`Ki`、`Kd`，PID 参数属于后续模拟量循迹实验。

## 碰撞后识别变差的排障提醒

实车测试中，小车发生碰撞后出现黑白线识别不清。逐路检查发现，只有最左侧的 LINE4（PB1）模块受影响；重新调节该模块的蓝色电位器后，黑白切换恢复稳定。

遇到类似现象时，先不要改程序和 PWM 参数，按下面的顺序检查：

1. 架空车轮并停止电机，逐个把四个模块放到白面和黑线上，观察比较器指示灯能否稳定切换。
2. 如果只有一路异常，优先检查该模块是否被撞歪、离地高度是否变化、插线是否松动，以及电位器阈值是否漂移。
3. 如果四路同时异常，再检查公共电源、地线、传感器整体高度和环境中的强红外光。
4. 如果停车时正常、启动电机后才异常，再检查振动、电源压降和电机干扰。

本次实测结论：环境变暗和程序并不是主要原因，最左侧模块受到机械影响后阈值改变才是根因。
