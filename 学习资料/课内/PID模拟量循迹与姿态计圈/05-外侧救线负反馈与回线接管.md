# 外侧救线负反馈与回线接管

## 1. 固定转角不等于已经回到轨迹

MPU6050 只能说明车身大约转过多少角度，不能说明黑线已经处于循迹传感器的有效区域。掉头结束后必须增加一个低速回线阶段，由外侧数字传感器和中间模拟传感器共同决定何时恢复 PID。

## 2. 外侧救线为什么需要锁存

外侧传感器触发后，如果下一帧刚释放就直接返回 PID，黑线可能仍未进入中间区域。锁存状态会记住正在向左还是向右救线，即使外侧已经释放，也继续保持修正，直到中间传感器稳定确认黑线。

当前回中条件为：

- 两个外侧数字传感器都已经释放；
- 左右中间 ADC 都不低于 `2000`；
- 左右 ADC 差值绝对值不超过 `500`；
- 上述条件连续满足 3 个新的 20 ms 样本。

这些数值是初始标定值。如果实车黑线对应低 ADC，应调整极性或阈值，不能继续盲目修改 PID。只有 ADC/DMA 成功产生的新快照才会增加确认次数，20 ms 时钟到达但采样失败时不会重复使用旧数据冒充新样本。

救线和回线最多持续 150 个有效样本，约 3 秒。超过预算仍未回中时，控制器将左右目标清零并上报 `LINE / BAD VALUE`，避免阈值错误或传感器故障导致小车无限转圈。

## 3. 为什么交接时重新低速启动

黑线刚回到中间时，车身通常仍有角速度。如果立即恢复此前已经爬升到 `3700` 的基础速度，很容易再次冲出。因此回中确认完成后把 PID 基础速度恢复到 `1800`，再按原软启动步长逐渐增加。

## 4. 掉头速度来自哪里

掉头阶段现在使用左右轮反向 `5000/-5000`，两轮指令差为 `10000`。它能以较小半径、更高角速度完成粗掉头。为补偿停车后的惯性过转，当前待测控制目标为 $170^\circ$；达到目标后切换为 `2400/700` 的低速回线，速度与精度由不同阶段负责。MPU6050 DMP 保持 $100\,\mathrm{Hz}$；在两秒完成 $170^\circ$ 控制目标时，相邻样本的平均角度变化约为 $0.85^\circ$，没有必要仅因电机提速就把 DMP 输出率翻倍。
