# 分级速度与持续时间判断

## 1. 为什么不能只提高基础 PWM

统一提高基础速度会同时提高直道和弯道速度。直道可能缩短用时，但传感器发现偏离到电机产生足够转向之间仍存在延迟，因此弯道更容易越过黑线。

更合理的做法是根据循迹置信度选择速度：稳定居中时加速，持续偏离时先减速，再纠偏。

## 2. 当前四级行为

```text
稳定居中约 200 ms
→ 基础速度逐步提高到 5000

持续偏离约 60 ms
→ 目标速度降低到 3300，PID 纠偏最大为正负 2400

同方向误差达到弯道阈值并连续 3 个样本
→ 进入强 PID，输出约放大 1.5 倍，弯道目标速度 4200

如果外侧 DO 与瞬时 ADC 误差方向冲突
→ 以外侧 DO 的左右方向为准，ADC 只决定纠偏幅度

外侧候选出现后的前两个样本
→ 已按外侧方向执行普通 PID；第 3 个连续样本才切换为强 PID，避免确认期间先朝错误方向转

外侧 DO 只短暂触发或随后完全丢线
→ 保持该侧方向直到中间稳定回线，ADC 小误差和相反瞬时符号不能覆盖外侧方向

只有一个居中样本或刚退出强 PID
→ 不立即解除方向；连续 3 个居中样本后才退出，并同步 PID 历史，避免残留微分造成反向回摆

中间双传感器重新同时检测到黑线
→ 继续保持原纠偏方向约 120 ms，连续 6 个有效样本后才退出救线

完全丢线约 100 ms
→ 按最后偏差方向以 2400/700 低速搜索
```

外侧传感器不再单独触发固定大差速，避免两个轮子速度差过大导致原地卡住。只有完全丢线才进入低速搜索。循迹找线不再设置主动停止超时；真正的传感器通信或硬件致命故障仍会触发停车。

## 3. 为什么降速比加速快

当前每个有效 20 ms 样本最多加速 `60`，但可以降速 `250`。这样直道上的加速较平滑，而检测到持续偏离后能够更快降低动能，为纠偏留下空间。

## 4. 为什么外侧传感器需要确认两次

外侧数字传感器是开关量，黑线边缘、车体振动或模块阈值都会造成单帧翻转。连续两个新样本确认约等于 40 ms 去抖，可以过滤单次抖动，同时不会让真正的急弯等待太久。

进入救线后若反侧外沿突然触发，也必须连续确认两次才改变救线方向。完全丢线时只保留最后一次仍有有效黑线迹象时的偏差方向，不能让白面上的 ADC 噪声决定搜索方向。

单次外侧候选或第一帧完全丢线会立即开始向较低速度靠近，但还不会立刻进入强救线或丢线搜索。这是“先减速、后确认动作”的安全策略。

## 5. 参数调整顺序

1. 先确认黑线 ADC 阈值和传感器极性。
2. 再确认普通偏离的 `3300` 与已识别弯道的 `4200` 是否合适。
3. 调整弯道误差阈值和强 PID 增益。
4. 最后逐步调整 `5000` 快速速度。

不要同时改变快速速度、PID 和外侧救线参数，否则实车结果无法说明是哪一个变量起作用。
